# Support

## I need help using excel-lite

1. Read [`docs/troubleshooting.md`](docs/troubleshooting.md) — it covers the errors people
   actually hit: "not a zip", sheet not found, dates off by a day, memory pressure, bundler
   warnings.
2. Read the relevant guide: [`docs/reading.md`](docs/reading.md),
   [`docs/writing.md`](docs/writing.md), [`docs/cli.md`](docs/cli.md).
3. Search [issues](https://github.com/horizonbymuneeb/excel-lite/issues?q=is%3Aissue).
4. If nothing matches, open an issue with your version, platform, the code you ran, and what
   you expected vs. what happened. A minimal repro file helps enormously.

## I found a bug

Open an issue using the bug template. If it involves data corruption or a security problem,
follow [`SECURITY.md`](SECURITY.md) instead of opening a public issue.

## I want a feature

Open an issue describing the use case, not just the API you imagined. Features that keep the
package small and the API surface flat are the ones that get in; see [`ROADMAP.md`](ROADMAP.md)
for what is already planned.

## I want to contribute

Start with [`CONTRIBUTING.md`](CONTRIBUTING.md). Issues labelled `good first issue` are
scoped to be finishable in an evening.

## Commercial support

There is none — this is a spare-time, MIT-licensed project. Paid support is not offered, but
well-scoped fixes can be sponsored via the issue thread.
